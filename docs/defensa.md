# Guion de defensa

1. Crea un perfil de prueba. Consulta su historial, cambia el alias y deja el borrado para después de jugar.
2. Completa un nivel en menos de 45 segundos con menos de dos puntos de daño. La interfaz anuncia el generador de desafío en Scala.
3. Completa otro nivel con dos puntos de daño para mostrar recuperación. Completa uno en 45 segundos o más con menos de dos puntos de daño para mostrar equilibrio. Las tres reglas tienen respaldo en JUnit.
4. Pierde toda la vida, abre Perfiles y muestra la partida guardada. Elimina un perfil de prueba para mostrar el último paso del CRUD.
5. Cambia `recoveryDamage` de 2 a 1 en el JSON, reinicia y demuestra el cambio con un punto de daño.

Cada integrante debe registrar sus propios issues con evidencia de pruebas, dos PR sustanciales y dos revisiones útiles a otra persona. En la defensa cada integrante debe explicar una decisión y realizar un cambio en vivo.
